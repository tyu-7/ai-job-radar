# Daily brief format

Use this compact order for each run.

## 1. Run summary

- Search window and sources checked.
- Counts: new, updated, duplicates skipped, and unverified.
- Tracker save result.

## 2. New high-fit roles

For each role include: priority, company, role, business, location, cohort, publication/deadline, score, direct link, verified match reason, primary risk, and recommended next action.

If there are no new high-fit roles, say so directly and list at most three still-open backlog roles. Do not add low-quality results to meet a quota.

## 3. Today's actions

Select at most three roles. For each, provide:

- why it should be handled today;
- three to five resume keywords supported by candidate evidence;
- two likely interview questions linked to real candidate experience.

## 4. JD signal update

Summarize recurring keywords and any newly observed requirement. Keep counts traceable to the roles included in the run.

## Fact labels

- `Verified`: stated on a currently accessible source.
- `Inference`: reasoned recommendation based on verified facts.
- `Unverified`: missing or inaccessible information that must be checked before applying.
